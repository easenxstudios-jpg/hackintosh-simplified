    Set up macOS on this PC

    This wizard checks your PC, walks you through Windows and BIOS settings, and prepares a macOS USB drive.

    Early preview. Use it at your own risk. The setup this wizard creates hasn't been boot-tested on real PCs yet, so it may need fixes. Changing BIOS settings or installing macOS can lose data if something goes wrong.

    What you'll need

    An empty USB drive of at least 16 GB, a wired or Wi-Fi connection, about an hour, and a separate drive or a backup of your files.

    Installing macOS on non-Apple hardware may break Apple's software license, so check what applies to you. This project isn't affiliated with Apple or OpenCore.

    Set up the BIOS

    Do this when the USB is ready, because you'll restart. Press Del, F2 or F10 at startup to open the BIOS. Names vary by maker, and some settings may not exist on your PC, which is fine.

    Don't change anything you're unsure about. Don't update the BIOS or change CPU voltage for this. If BitLocker is on, have your recovery key ready.

    Install macOS

    Drivers load before macOS starts

    OpenCore loads the drivers on your USB while the text scrolls by at startup, so macOS can see your hardware from the first boot. That covers processor, graphics support, audio, USB and Ethernet.

    What can't be ready at first boot

    Steps

    1. Restart, open your BIOS, and make the settings from the BIOS step.
    2. Open the boot menu (often F8, F11 or F12) and choose the USB's UEFI entry.
    3. In the OpenCore menu, choose the macOS installer, sometimes named “macOS Base System” or “dmg”.
    4. Wait while text scrolls. The first start can take several minutes.
    5. Open Disk Utility, choose View > Show All Devices, and erase only the drive for macOS as APFS with GUID Partition Map. Check the name and size carefully.
    6. Choose Reinstall macOS. The PC restarts several times. Choose the macOS drive in the OpenCore menu each time.

    Make it fast and finish up

    1. Install to an SSD, never to a USB 2 drive or adapter.
    2. Open Hackintosh Simplified for Mac and press Fix Problems.
    3. For NVIDIA cards, use NullMoth's 1401 app from its official page.
    4. Build a USB map, so ports reach full speed.
